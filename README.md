## Selected work

**[Real-Time Death Detection + LLM Summarization](https://github.com/Adieltheanalyst/realtime_death_detection)**
Real-time computer vision pipeline that detects player death events in gameplay video using template matching, then sends a rolling 10-second event buffer to an LLM for a plain-English summary. 2–3 second death-to-summary latency, 80% precision on an independent evaluation clip, and a calibration toolchain that adapts to new resolutions in about five minutes without retraining.
`Python` `OpenCV` `Gemini API`

**[Macro-Anchored Route-to-Market Simulator](https://github.com/Adieltheanalyst/Macro-Anchored-Route-to-Market-Simulator)**
Forecasts localized FMCG stockouts across 1,000+ Nairobi retail nodes by combining inventory data, spatial clustering and a 14-year mobile money liquidity series. Random Forest reached 91% accuracy and 79% precision, and macro liquidity outperformed calendar-based demand indicators.
`Python` `Statistical Modeling`

**[Mamba from Scratch](https://github.com/Adieltheanalyst/MambaBlock)**
The Mamba architecture implemented from the original paper.
`Python` `PyTorch`

**[RAG School Assistant](https://github.com/Adieltheanalyst/Rag-school-assistant)**
Retrieval-augmented assistant for dense technical PDFs. The hardest problem was extracting mathematical notation reliably.
`Python` `Vector DBs` `Embeddings`

**[Upwork Proposal Agents](https://github.com/Adieltheanalyst/upwork_proposal_agents)**
Agentic workflows that generate client-tailored proposals using external APIs and prompt optimization.
